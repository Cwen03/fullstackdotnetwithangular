## **Lab 4: Class Binding**

### **Task:** Apply a CSS class dynamically based on a condition.

```typescript
// app.component.ts
export class AppComponent {
  isActive = true;
}
```

```css
/* styles.css */
.active {
  background-color: green;
  color: white;
}
```

```html
<!-- app.component.html -->
<div [class.active]="isActive">
  This div is {{ isActive ? 'active' : 'inactive' }}.
</div>
```

## **Lab 8: Combined Binding (Event + Property Binding)**

### **Task:** Disable button conditionally and trigger an event.

```typescript
// app.component.ts
export class AppComponent {
  isDisabled = false;

  toggleButton() {
    this.isDisabled = !this.isDisabled;
  }
}
```

```html
<!-- app.component.html -->
<button [disabled]="isDisabled">Action</button>
<button (click)="toggleButton()">
  {{ isDisabled ? 'Enable' : 'Disable' }} the Action Button
</button>
```
