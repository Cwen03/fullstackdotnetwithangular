# 🏥 **Case Study: HealthCare Pro - Patient & Appointment Management System (Angular 15)**

### **Objective:**
Build a simple healthcare application using Angular 15 that allows:
- Displaying a list of patients.
- Scheduling appointments.
- Using different Angular concepts such as Components, Directives, Data Binding, Life Cycle Hooks, and Pipes.

---

## **1. Application Features:**
- Display patient list (component-based)
- Appointment booking (forms and two-way data binding)
- Highlight critical patients using custom directives
- Filter and format data using pipes
- Track component lifecycle with hooks

### **b) Patient List Component**

```typescript
// patient-list.component.ts
import { Component, OnInit } from '@angular/core';
import { PatientService } from '../../services/patient.service';

@Component({
  selector: 'app-patient-list',
  templateUrl: './patient-list.component.html',
  styleUrls: ['./patient-list.component.css']
})
export class PatientListComponent implements OnInit {
  patients: any[] = '';
  searchText: string = '';

  constructor(private patientService: PatientService) {}

  ngOnInit() {
    this.patients = this.patientService.getPatients();
  }
}
```

```html
<!-- patient-list.component.html -->
<input type="text" [(ngModel)]="searchText" placeholder="Search Patients..." />
<ul>
  <li *ngFor="let patient of patients | search:searchText" [appCriticalPatient]="patient.critical">
    {{ patient.name }} ({{ patient.dob | age }} years old)
  </li>
</ul>
```

### **c) Appointment Form Component**

```typescript
// appointment-form.component.ts
import { Component } from '@angular/core';
import { AppointmentService } from '../../services/appointment.service';

@Component({
  selector: 'app-appointment-form',
  templateUrl: './appointment-form.component.html',
  styleUrls: ['./appointment-form.component.css']
})
export class AppointmentFormComponent {
  appointment = {
    patientName: '',
    date: ''
  };

  constructor(private appointmentService: AppointmentService) {}

  bookAppointment() {
    this.appointmentService.book(this.appointment);
    this.appointment = { patientName: '', date: '' };
  }
}
```

```html
<!-- appointment-form.component.html -->
<form (ngSubmit)="bookAppointment()">
  <label>Patient Name:</label>
  <input type="text" [(ngModel)]="appointment.patientName" name="patientName" required />
  <label>Appointment Date:</label>
  <input type="date" [(ngModel)]="appointment.date" name="date" required />
  <button type="submit">Book Appointment</button>
</form>
```

## **4. Directives**

### **Custom Directive: Highlight Critical Patients**

```typescript
// critical-patient.directive.ts
import { Directive, ElementRef, Input, OnChanges } from '@angular/core';

@Directive({
  selector: '[appCriticalPatient]'
})
export class CriticalPatientDirective implements OnChanges {
  @Input('appCriticalPatient') isCritical: boolean = false;

  constructor(private el: ElementRef) {}

  ngOnChanges() {
    if (this.isCritical) {
      this.el.nativeElement.style.color = 'red';
      this.el.nativeElement.style.fontWeight = 'bold';
    } else {
      this.el.nativeElement.style.color = 'black';
    }
  }
}
```

## **5. Pipes**

### **a) Age Pipe**

```typescript
// age.pipe.ts
import { Pipe, PipeTransform } from '@angular/core';

@Pipe({
  name: 'age'
})
export class AgePipe implements PipeTransform {
  transform(value: string): number {
    const dob = new Date(value);
    const diff = Date.now() - dob.getTime();
    const age = new Date(diff);
    return Math.abs(age.getUTCFullYear() - 1970);
  }
}
```

### **b) Search Pipe**

```typescript
// search.pipe.ts
import { Pipe, PipeTransform } from '@angular/core';

@Pipe({
  name: 'search'
})
export class SearchPipe implements PipeTransform {
  transform(patients: any[], searchText: string): any[] {
    if (!searchText) return patients;
    return patients.filter(p => p.name.toLowerCase().includes(searchText.toLowerCase()));
  }
}
```

- **Age pipe** calculates the patient's age from DOB.
- **Two-way data binding** is used in forms.
- **ngOnInit lifecycle hook** fetches initial patient data.
